# 【鼓医“互联网+护理”平台正式发布】线上预约，三甲医院护士上门服务！

> 更新时间：2026-09-17 (UTC+8)

点击上方“**南京鼓楼医院**”可订阅哦！

去医院看病，可不是一件轻松的事儿，尤其是对那些失能、半失能老人、长期慢性病患者或者需要特殊治疗与护理的患者来说则更是不易，因此居家护理一直是鼓楼医院护理人不懈探索的领域。自从2019年2月国家卫生健康委出台《“互联网＋护理”服务试点工作方案》以来，鼓楼医院作为江苏省和南京市的试点单位，形成了具有鼓医特色的“互联网＋护理”服务模式，截止11月22日，共有116位患者收案，81位患者预约服务共115次，其中线下服务73人次，线上服务42人次，获得了患者及照护者的一致好评。

“鼓楼模式”的“互联网+护理”服务聚焦危重患者或疑难复杂病例的延续性护理服务，从技术上解决全程护理服务“最后一公里”的问题 ，第一批试点项目聚焦危重患者及疑难复杂病例的延续性护理服务。

**2019年12月5日上午，鼓楼医院“互联网+护理”平台正式对外发布。****
**

**南京鼓楼医院党委书记彭宇竹强调了三级医院开展“互联网+护理**”服务所发挥的引领作用和重要意义，并对鼓楼医院“**互联网+医疗**”服务以及“**单病种中心化信息平台**”的标准建设和规范管理提出了展望。

**居家腹膜透析护理**

从原先为首次患者居家访视照护环境及培训腹膜透析居家护理技能发展到为行动不便的患者上门更换腹透导管、处理腹透相关并发症，节约了患者往返医院过程中家庭人力成本及交通成本，获得患者与家属的好评。

**伤口/疑难造口护理**

聚焦慢性创面，或有其他全身合并症的伤口、疑难造口等，将三级医疗机构专业的护理技术服务真正意义上延伸至患者家庭，缩短创面愈合时间，同时减轻家庭的照护负担。

**糖尿病管理**

以线上服务为运行方式，护理技术性操作专科项目负责人根据对接社区的服务能力、服务项目的难易程度进行转介。对于技术难度大的服务项目，专科护理人员采取上门服务或下社区现场指导的方式，一方面对居家糖尿病患者进行分层管理，同时对基层医疗机构进行技术输出，提高基层医疗机构的服务能力。

**居家安宁疗护项目**

通过线上服务或线下服务满足患者及家属需求，专科负责人对其需求进行评估后将患者转介至下一级医疗机构，原则上我院安宁疗护专项组护理人员或专科团队需对每一例实施安宁疗护的患者首次居家或转介社区进行上门评估，聚焦疑难症状管理、难以控制的疼痛等问题，主体医疗机构负责对患者结案。

**哪些患者可以申请？**

**安宁疗护收案标准：**

1. 生存期≤6个月的末期肿瘤患者（必须经两位住院医师共同评定）；

2. 患者居住地为南京市鼓楼区、玄武区、建邺区、浦口区、秦淮区、江宁区、雨花区；

3. 患者和家属须签署安宁疗护知情同意书（内容包括放弃延长生命的治愈性医疗手段和放弃延长濒死期的急救医疗措施）；

4. 病人及家属均认同接受安宁居家疗护模式，家属具有照顾意愿及能力，且能配合医务人员的指导。

**腹膜透析收案标准：**

1. 新置管腹膜透析患者，首次需要通过家访评估居家腹透环境，换液操作及相关指导。

2. 长期卧床行动不便的腹膜透析患者，主要提供腹透外接短管更换，相关检验项目的标本留取服务。

3. 线上无法完成的并发症处理。

**糖尿病收案标准：**

1. 为我院内分泌科出院糖尿病患者。

2. 主动要求提供“互联网+护理”服务的患者，需护士首次进行评估。

3. 无精神疾病。

4. 无糖尿病急性并发症患者。

**伤口护理收案标准：**

1. 为我院外科门诊就诊，伤口护理室换药的患者；

2. 患者/照护者主动要求提供“互联网+护理”服务，签署收案同意书；

3. 患者/照护者无精神障碍、无吸毒、无酗酒史等；

4. 非高度传染性伤口（艾滋病、气性坏疽）患者；

5. 需收案护士进行首次评估，“互联网+护理”服务工作室审核通过。

**如何申请“互联网+护理”？**

**↑点击图片可放大查看**

**收案**

患者在南京鼓楼医院挂号就诊，由相应科室现场评估并签署知情同意书，完成患者受案。

**注册**

扫描微信小程序“南京鼓楼医院”，完成账号注册，进入首页，找到“互联网+护理”，点击开始体验。

**完善信息**

进行照护人身份认证，添加已在鼓楼医院完成受案的照护患者，并完成患者身份证号绑定和认证（每位患者只能被一位照护人绑定）

**预约服务**

选择照护患者、服务项目、预约上门时间（可预约时间段为7:00-19:00，请提前24小时预约）、填写服务地址、签署知情同意书后即可提交预约订单。

**服务评价**

完成服务后，还可以在线对上门的护士进行评价，评价内容包括准时性、服务规范、技术熟练度以及对患者感受的关注度等等。

**在线咨询服务**

除了预约上门服务，还可以在小程序上预约在线咨询服务。以图文咨询为主要形式，咨询时间8:00-20:00。

**注意：**

“互联网+护理”服务的目标人群原则上为出院患者或罹患疾病且行动不便的特殊患者，不接受急诊服务。

此外，鼓楼医院“互联网+护理”服务以连续性护理服务为目标，智能导入患者就诊资料、居家医嘱等信息，同时通过对每次“互联网+护理”服务的记录予以留痕，为患者建立延续性健康照护档案。
