# 青大附院举办首届“教学名师工作坊”开班仪式

> 更新时间：2026-09-16 (UTC+8)

为传承青大附院优良教学传统，提升中青年教师教学能力和综合素质，青大附院成立“教学名师工作坊”，首届遴选10位资深的临床专家作为工作坊导师、90余位中青年教学骨干作为工作坊学员。

  //  

2月9日，青大附院举办首届“教学名师工作坊”开班仪式。青大附院党委书记、青大第一临床医学院党委书记蒋光峰，青大附院院长李环廷、副院长徐岩，青大第一临床医学院党委副书记邢晓明，青大附院副院长陶昊、院长助理魏丽丽出席仪式，“教学名师工作坊”导师及学员、临床教师和学生代表共200余人参加仪式。邢晓明副书记主持仪式。

蒋光峰书记讲话，他表示，教育大计，教师为本。近年来，医院坚持把人才作为发展第一资源，把教师队伍建设作为医院发展的重点工作，培养锻造了一支传承创新的高水平教师队伍。医院成立“教学名师工作坊”，旨在通过传、帮、带等方式，培育一批中青年教学骨干，推动教学改革，创新教学方法，提升教学质量，增强教学实效。他强调，要深化课程建设，打造一批“金课”，争取实现省级及以上一流课程建设的新突破；要加强师资建设，培养一批“准名师”，打造一支能够胜任医学教育发展变革和人才培养需要的高水平教师队伍；要加强教研教改，结出一批成果，积极开展高质量的教学研究，使“教学名师工作坊”真正成为教师发展的平台；要发挥示范引领，传承教书育人、勇于奉献的理念，及时总结先进教学经验，吸引更多临床教师投身于教学工作。医院将以“教学名师工作坊”建设为契机，坚守“立德树人”根本任务，提高人才培养质量，不断推进临床—教学—科研整合式一体化学院型医院建设，促进医院高质量发展再上新台阶！

蒋光峰书记、李环廷院长与导师代表周岩冰教授、邓婧教授共同揭牌

出席仪式的院领导与导师分别为学员颁发证书

李环廷院长与导师代表田字彬教授、赵桂秋教授、徐文坚教授签订“教学名师工作坊”导师协议书。

导师代表王宏桥教授、王强教授、王振光教授分别与学员签订“教学名师工作坊”学员协议书

导师代表田字彬教授发言。他表示，作为“教学名家工作坊”的导师，要牢记为党育人、为国育才的使命，传承创新，培养一支德才兼备的优秀临床教师队伍，践行作为医者、师者的使命和担当。

学员代表李泽群发言。他表示，将以导师为榜样，爱岗敬业、严谨治学，不断提升教学水平与综合素质，成长为教学水平过硬、创新能力强的临床骨干教师。

开班仪式结束后，周岩冰教授作《如何做一名好老师》专题讲座。周岩冰教授以扎实的临床教学理论知识为指导，结合自身经历，为大家讲述了优秀临床教师成长过程中应具备的技能与素质，使所有学员受益匪浅。
